# 数据库提示词

Updated: 2026-07-31

AutoFilm Core 的 AI 行为提示词保存在 SQLite `prompt_configs` 表中。代码内仍保留
每类提示词的系统默认模板，作用仅限首次初始化、默认版本升级和“恢复默认值”。
运行时的模型请求始终从数据库读取。

## 提示词分类

| Key | 使用位置 | 上下文 |
| --- | --- | --- |
| `agent.main` | 成员日常聊天、媒体搜索与操作 | 保留最近 80 条会话消息 |
| `conversation.summarizer` | 切换作品时整理上一影视主题 | 独立无工具请求 |
| `subtitle.captcha.system` | SubHD 验证码识别系统指令 | 独立单次视觉请求 |
| `subtitle.captcha.user` | 随验证码图片发送的识别要求 | 独立单次视觉请求 |
| `subtitle.cleaner` | 字幕广告判断 | 独立单次请求 |
| `watchlist.evaluator` | 定时追更条件判断 | 独立只读工具会话 |

管理界面的“提示词”页面显示当前内容、是否自定义、默认版本和更新时间。保存后，
下一次对应的模型请求立即读取新内容，不需要重启容器，也不会改写已经保存的聊天记录。

## 默认版本

每个代码默认模板有独立版本号。

- 数据库记录未自定义时，新版本启动会自动替换旧默认内容。
- 数据库记录已经自定义时，升级不会覆盖管理员内容。
- “恢复默认值”会写入当前代码版本的完整默认内容，并把记录恢复为未自定义状态。
- 提示词不得为空；所有管理接口均使用现有管理员会话认证。

## 旧版提示词迁移边界

主 Agent 默认提示词保留了仍适用于当前架构的规则：

- TMDB 内容识别、Jackett 资源搜索和并行字幕搜索；
- 片源、分辨率、编码、HDR、音轨、大小、热度与字幕匹配评估；
- SubHD 详情、翻译质量、语言、格式和评论判断；
- 单任务、分集批量任务、备用磁力和 115 短时失败规则；
- OpenList 绝对路径、Jellyfin 远端刷新、媒体流和图片管理；
- SubHD 影片页完整列表、成员级多包 workspace、Jellyfin 字幕管理、独立验证码
  上下文、逐文件全量广告清理和 ASS 样式；
- 主动只读查询、多人权限、凭据安全和追更。

以下旧规则没有迁移，因为对应能力已经删除或转移到其他组件：

- Telegram HTML、Inline Button 和 Telegram 专属语气；
- Alist 到本地的目录同步、软链接、rclone 和本地文件删除；
- 下载后等待 30 秒扫描、本地精准扫描插件和 Nginx 改写；
- 旧版追更结果标记；当前独立评估器使用 `[MATCH]` 与 `[NO_MATCH]`。

旧版会话级累积字幕索引已改为任务级 `workspace_id`。它不写数据库，但可以在一次任务
内累计多个压缩包，并为每个解压文件提供不可变 `workspace_file_id`。数字序号不再
出现在 Agent 工具协议中。

## 运行时附加信息

Core 在数据库主提示词之外动态加入当前服务器时间和已保存的较早影视主题摘要。
服务器时间每次请求重新生成，不属于可编辑行为规则。主题摘要本身由
`conversation.summarizer` 生成，其提示词仍在数据库和管理页面中维护。
