# 管理界面视觉规范

Updated: 2026-07-29

## 视觉来源

Core 管理界面以旧 AutoFilm 前端源码为视觉基准，不建立独立品牌视觉。基准文件包括：

- 旧版 `src/app/globals.css` 的 shadcn 中性色设计令牌。
- 旧版 `src/app/page.tsx` 的顶部栏、居中容器和横向标签布局。
- 旧版 `src/app/login/page.tsx` 的 350px 居中登录卡片。
- 旧版 `src/components/ui` 的按钮、输入框、卡片和弹窗规格。

Core 增加的成员、聊天渠道、媒体服务、任务和 Agent 页面继续使用同一套组件，不使用
另一套后台模板。

## 页面结构

桌面端结构为：

1. 带底部边框的顶部栏，左侧显示 Film 图标，右侧显示当前用户和登出按钮。
2. 最大宽度 1280px 的居中内容区。
3. 灰色圆角背景内的横向标签导航，当前标签使用卡片背景和轻阴影。
4. 页面标题与说明。
5. 使用边框卡片组织业务内容。

窄屏继续保留横向标签，超出宽度时横向滚动；内容卡片改为单列。界面不切换成另一套
抽屉或侧栏布局。

## 颜色、阴影与字体

- 管理界面固定使用深色，不读取系统主题，也不提供主题切换。
- 页面背景和卡片接近黑色，正文接近白色。
- 次级背景使用中性深灰，边框使用深灰。
- 主按钮使用白底黑字。
- 绿色、黄色和红色只表达成功、警告和错误等状态。
- 不使用紫色品牌色、渐变背景、彩色光晕或渐变 Logo。
- 正文字体使用 Geist Variable，并保留中文系统字体作为回退。
- 卡片、按钮和输入框使用黑色外阴影与极弱的白色内高光，形成深色界面的层次。

## 动画

- 横向标签的活动背景使用弹簧动画移动，参数与旧版一致：
  `stiffness: 300`、`damping: 30`。
- 页面标签切换按方向横向进入和退出，使用同一组弹簧参数。
- 弹窗使用遮罩淡入和内容缩放进入，通知从底部淡入。
- 按钮保留颜色、边框、阴影和按压位移过渡。
- 系统启用减少动态效果时，将动画时长降到最低。

## 基础组件

- 登录卡片：默认宽度 350px，初始化卡片因多一个字段扩展到 390px。
- 按钮：高度 36px、6px 圆角、14px 字号。
- 输入框：高度 36px、6px 圆角，焦点使用中性前景色描边。
- 卡片：12px 圆角、1px 边框和轻阴影。
- 弹窗：黑色半透明遮罩、居中边框卡片。
- 状态标签：允许使用语义色；普通标签使用中性灰。

## 修改边界

视觉修改不能改变 API、权限、路由或业务表单字段。新增管理页面应复用
`components/Ui.tsx` 和现有 `styles/` 设计令牌，不在页面内部新增品牌颜色。
